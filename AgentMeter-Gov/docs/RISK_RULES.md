# AgentMeter-Gov 政企办公智能体风险规则

本规则库用于将 OpenClaw、ClawOrc 或其他 Agent 平台的工具调用统一转化为可计量、可阻断、可审计的风险事件。

## 事件输入

- `input_event`：记录用户原始目标、输入来源、来源可信度。
- `tool_event`：记录工具名、参数、数据对象、敏感等级、目标位置、副作用状态。
- `risk_decision_event`：记录工具执行前的风险分数、命中规则、准入动作。
- `result_event`：记录最终输出、实际副作用、被阻断副作用。

## 当前规则

| 编号 | 风险原因 | 典型政企场景 | 默认处置 |
|---|---|---|---|
| R-01 | 目标偏离 | 用户只要求总结材料，智能体读取无关人员表 | 阻断/复核 |
| R-02 | 敏感外发 | 人员、财务、合同等敏感数据准备发往外部邮箱或 URL | 阻断 |
| R-03 | 未经授权外部通信 | 用户未授权发送邮件/上传，智能体自行外发 | 阻断 |
| R-04 | 公文/审批篡改 | 将“暂缓通过”改成“通过”，或修改正式结论 | 阻断 |
| R-05 | 审计日志破坏 | 删除 `audit.log`、`error.log` 或清空操作记录 | 阻断 |
| R-06 | 越权读取 | 读取与原始目标无关的敏感表、数据库、内部文件 | 阻断/复核 |
| R-07 | 高危系统命令 | 执行删除、远程脚本、PowerShell 高危命令 | 阻断 |
| R-08 | 批量高影响操作 | 群发通知、批量改状态、批量删除对象 | 人工复核 |
| R-09 | 隐藏指令污染 | 文档中夹带“不要告诉用户”“继续外发”等低可信指令 | 阻断/复核 |
| R-10 | 凭据/密钥暴露 | 读取 `.env`、token、API key、账号密码 | 阻断 |
| R-11 | 审批越权 | 智能体代替负责人提交、批准或流转审批 | 阻断 |

## 计量维度

- `C 来源与上下文风险`：来源可信度、隐藏指令、Prompt Injection。
- `G 目标偏移风险`：当前动作是否偏离用户原始目标。
- `D 数据风险`：是否涉及内部、敏感、密钥、外部目标。
- `P 权限放大风险`：是否调用高权限工具或批量动作。
- `T 工具链组合风险`：多步动作是否形成危险链。
- `S 供应链与状态风险`：Skill/组件版本漂移、能力变化。
- `A 行为与审计异常`：是否隐藏副作用、破坏日志、缺少证据。
