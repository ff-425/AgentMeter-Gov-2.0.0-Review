# AgentMeter-Gov 2.0.0

本仓库提供 2026-09-14 最终修订的 2.0.0 源码。以下列出该版本的行为、改动及验证范围。

## 安装修复

- 修复 Windows 静默安装或升级后桌面巡检宠物未自动恢复的问题。

## 评分与执行状态修复

- 任务列表和详情展示任务最高风险分，按阻断、人工复核、放行汇总处置；后续低风险调用不覆盖此前风险。
- 最后一条助手消息报错或终止时，记录失败及脱敏原因；恢复后的历史错误不影响正常结束。
- 后台命令启动与轮询中的状态记为等待，工具错误和非零退出码记为失败。
- agent_end 表示任务运行结束，业务成功需对应回执。
- 新增风险汇总和执行状态测试，并更新 CI 与发行检查入口。

## 网络请求与 CI 修复

- 普通网络读取限定为可完整解析的单条字面量命令，区分 GET/HEAD、发送数据、上传、DELETE 和其他修改方法；未知选项、动态展开和组合命令不能获得读取豁免。
- shell 发送或修改请求需要用户明确要求对应动作并指定完整目标，仍需人工复核；只生成草稿、禁止发送或目标不符时阻断。保留正常读取和有界下载。
- GOV-BAT-002 的预期保持阻断，通过修正规则恢复阻断。另两项 GOV-INJ-003、GOV-STG-005 同步既有注入/凭证硬阻断策略，并在数据中记录预期调整依据。
- 本地发布检查纳入政务和安全场景；CI 同时覆盖 integration-core、main 和 PR，插件、后端、治理、监控独立运行并报告结果。
- 增加正常读取、合法下载、POST、上传、DELETE、循环、组合命令、动态输入、完整目标匹配和授权否定的回归。

## 修复

- 审批、拒绝按完整指令解析，避免将问题、引用、否定表述或混合业务请求误当作审批；保留审批编号、任务绑定、有效期和一次性放行约束。
- 区分自然语言预约时间与实际 AT 调度命令，区分代码讨论与具有明确执行或外传目标的延迟指令；实际攻击仍经过安全检查。
- 补充真实插件钩子的审批路由回归，覆盖有无待审批、错误编号、过期、跨会话、错误目标和单次使用。

## 性能

- 门控请求和后端恢复共享总超时，仅对明确尚未发出的连接失败重试，增加请求与风险计算阶段计时。
- 复用语义风险原型准备，减少重复分词和编码；不跨请求缓存用户输入。
- 复用监控日志快照与序列化响应；新证据、查询范围和任务状态变化时失效。
- 增加可还原全部字段的紧凑传输，配合 gzip 和条件请求降低重复传输与处理成本；保留认证、脱敏和历史数据。

## 评测数据

本仓库收录 [645 案例综合真机测评结果](EVALUATION_RESULTS.md) 及其 [结构化指标](../data/evaluation_metrics.json)。518 个攻击案例的综合防护成功率为 **99.03%**，AgentMeter 干预率为 **69.88%**，有害绕过率为 **0.97%**；127 个正常业务案例的放行率为 **92.13%**，硬误报率为 **3.94%**。

测评覆盖 2026-08-10 至 2026-09-06，涉及插件版本 0.3.0 至 1.1.11。该结果作为 2.0.0 公开仓库的综合测评基线，并非只针对 2.0.0 的独立复测。旧案例集、盲测集、原始会话及历史报告不在公开范围内。
