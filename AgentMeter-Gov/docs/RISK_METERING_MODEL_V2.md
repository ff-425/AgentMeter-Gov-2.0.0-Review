# AgentMeter-Gov 九因子风险计量模型 V2

## 1. 模型定位

AgentMeter-Gov 不是替代 OpenClaw 原生安全层，而是在 OpenClaw 工具调用前增加一层面向政企业务的风险计量与防控闸门。

模型目标是回答四个问题：

1. 用户原始目标是什么。
2. OpenClaw 实际工具链做了什么。
3. 这个工具链在政企场景下有什么风险。
4. 为什么本次分数应当放行、复核或阻断。

## 2. 九个风险因子

| 因子 | 名称 | 权重 | 核心含义 | 典型高风险场景 |
| --- | --- | ---: | --- | --- |
| C | 来源与上下文风险 | 0.10 | 输入来源是否可信，是否存在低可信文档、隐藏指令或提示注入 | 会议纪要隐藏指令、外部网页诱导越权 |
| G | 目标偏移风险 | 0.12 | 工具链是否偏离用户原始目标 | 只要求摘要却外发、只读审批却修改结论 |
| D | 数据风险 | 0.18 | 数据是否涉及内部信息、人员名单、手机号、身份证号、密钥或凭证 | 通讯录外发、读取 `.env`、读取 `.npmrc` |
| P | 权限放大风险 | 0.10 | 工具调用是否扩大智能体权限边界 | 命令执行、审批提交、批量删除 |
| T | 工具链组合风险 | 0.13 | 多步工具是否形成危险链路 | 读取敏感文件后邮件外发、数据库查询后上传 |
| S | 插件/Skill 供应链状态风险 | 0.08 | 插件或 Skill 是否存在版本漂移、声明能力不一致或新增高危能力 | 摘要 Skill 新增外联或命令执行 |
| A | 审计与行为异常风险 | 0.09 | 是否破坏审计证据、隐藏副作用或缺少证据字段 | 删除 audit.log、隐藏外发副作用 |
| I | 意图偏移风险 | 0.12 | 用户目标与实际工具动作是否一致 | 总结任务变外发、只读任务变审批 |
| U | 用户习性偏移风险 | 0.08 | 当前行为是否偏离用户历史常态 | 平时只做摘要的用户突然读取凭证 |

## 3. 评分公式

```text
score = min(100, round(sum(F_i * W_i) + combo_bonus))
```

其中：

- `F_i` 是第 i 个因子的 0-100 分。
- `W_i` 是该因子的权重。
- `combo_bonus` 是链式组合风险加分，例如“敏感读取 + 外部发送”“凭证读取 + 命令执行”。
- 硬阻断规则优先于总分阈值。

## 4. 阈值解释

| 分数区间 | 处置 | 解释 |
| --- | --- | --- |
| 0-39 | allow | 未命中关键政企风险链路，主要是公开数据、低影响读写或正常办公动作 |
| 40-74 | human_review | 已出现外发、批量、正式文件写入、敏感中转或意图偏移，需要负责人确认 |
| 75-100 | block | 命中敏感数据外发、凭证读取、审计破坏、危险命令、未授权审批/篡改等高危链路 |

## 5. 风险贡献解释

每次判定输出：

- 总分。
- 处置动作。
- 命中规则。
- 每个因子的原始分、权重、贡献分。
- Top 3 贡献因子。
- 阈值解释。
- 硬阻断或强制复核原因。

示例：

```json
{
  "total_score": 88,
  "action": "block",
  "top_contribution_summary": [
    "D 数据风险贡献16.2分",
    "T 工具链组合风险贡献11.96分",
    "G 目标偏移风险贡献10.32分"
  ],
  "threshold_explanation": {
    "band": "75-100",
    "action": "block",
    "explanation": "命中敏感数据外发、凭证读取、审计破坏、危险命令、未授权审批/篡改等高危链路，应在工具执行前阻断。"
  }
}
```

## 6. 计量特色

本模型的亮点不是简单关键词拦截，而是把 OpenClaw 的工具调用链转化为可解释的风险计量结果：

- 有因子定义。
- 有权重。
- 有阈值。
- 有贡献解释。
- 有样本回归。
- 有审计留痕。
- 可根据真实 OpenClaw 红队样本持续校准。

这部分可以作为中国计量大学团队的核心优势来讲。
